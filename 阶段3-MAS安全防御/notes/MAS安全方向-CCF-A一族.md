## 三、三个关键发现

### 1. 你的威胁模型，有一篇 CCF-A 正会论文几乎一模一样

**Lying with Truths（ACL 2026 正会）** 的设定：

> 多个合谋 Agent **只用真实的证据碎片**，通过**公开渠道**分发，**不需要隐蔽信道、后门或伪造文档**，就能操纵受害者 Agent 的信念。利用 LLM 的 overthinking 倾向，让受害者**自己把碎片拼成错误结论，并继续传播**。

**对照你的卫星攻击链**：
- ① 获取卫星运行参数 → 都是**真实信息碎片**
- ② 篡改认知范围使其合理化 → 「只用真话，让你自己推错」
- ③ 在篡改后认知下执行不合理操作 → 受害者内化后自己去做

**这不是比喻，是同一个攻击类型。** 这篇必须读。

### 2. 防御侧最该看的是 BlindGuard（ACL 2026 正会 + 开源）

- **无监督**，不需要标注"哪个 Agent 是恶意的"
- 分层编码：个体、邻域、全局交互
- 针对的正是 **propagation vulnerability**（恶意 Agent 通过相互交互扭曲集体决策）

**对你的价值**：卫星星座里你没法标注"哪颗星被攻陷了"，**无监督是刚需**。

### 3. SAIGuard 的机制跟 SSH 是同一思路，但对象不同

| | SSH | SAIGuard |
|---|---|---|
| 模拟什么 | 未来**动作序列**（轨迹树） | **通信状态**（交互图上的消息影响） |
| 检测依据 | 风险叶子占比 + 双阈值 | 与良性通信模式的**重构偏差** |
| 处置 | 剪枝 + **重采样** | **净化或重生成消息**（不隔离 Agent） |

**「不隔离、而是净化/重生成」跟 SSH 的「不终止、而是重采样」是同一个设计哲学。**

## 四、战略结论（这条最重要）

**SSH 看的是「动作序列上的未来」，MAS 这批看的是「通信图上的传播」。**

**你的卫星场景，其实更贴 MAS 这批。**

理由：
- 卫星多智能体攻击的本质是**消息在 Agent 之间传播、逐步污染认知**，不是单个 Agent 的动作序列
- 导师的「**连环锁**」= 每一环独立校验 → 更接近 **G-Safeguard 的拓扑干预** 和 **TopoSHIELD 的剪边**，而不是 SSH 的轨迹树
- 卫星星座天然是**分布式拓扑**，G-Safeguard / TopoSHIELD / BlindGuard 都在图/拓扑上作业

**所以研究方案的技术底座应该这么定**：

| 用途 | 选哪篇 |
|---|---|
| **威胁模型定义** | **Lying with Truths**（ACL 2026 正会）——认知合谋攻击 |
| **防御主参照（CCF-A + 开源 + 无监督）** | **BlindGuard**（ACL 2026 正会，★15） |
| **主动拦截机制** | **SAIGuard**（Findings，通信状态模拟 + 净化不隔离） |
| **拓扑干预（最像连环锁）** | **TopoSHIELD**（Findings，剪边 + 隔离社区）／**G-Safeguard**（ACL 2025 正会） |
| **单 Agent 动作层推演（补充）** | SSH |

**SSH 不用扔，但它从「主线」降成「单 Agent 动作层的一块」。**
