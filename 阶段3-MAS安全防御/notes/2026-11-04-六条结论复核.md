## 三、要改口径的四处

1. **Fides 不是 NeurIPS**。arXiv 2505.23643 真标题是 *Securing AI Agents with Information-Flow Control*（Fides 是系统名）。NeurIPS 2025 全量 proceedings 里搜不到；OpenReview 只有一条「Submitted to ICML 2026」。只能按 arXiv 预印本引。
2. **ToolSafe 是 Findings，不是正会**。不能计入 CCF-A。
3. **M=5 不是全局默认**。Table 1（AgentDojo）是 M=4、D=4；Table 2（ActorAttack，99.5%/96.0% 那组）和 Limitations 段才用 M=5。论文自己 Table 1 标题写「beam width 8 (M=4)」，正文又写 M=8 —— 记法自相矛盾，引用时带版本。
4. **1.3% 是 3B/235B 的算术**，不是实测开销；论文自己说 GPU 和功耗「non-negligible」。0% ASR 只在 Qwen3-235B 上成立（GPT-OSS-120B 是 0.7%）。

## 六、检索方法最大的漏洞

1. **反查参考文献会继承被引论文的盲区**：SSH 自己没引 ToolEmu / ShieldAgent / Pro2Guard / AgentSpec / SafeMCP，这几篇你从 SSH 反查永远查不到。
2. **「几乎全部集中在 2025Q4–2026」是采样造成的**：从近期论文反查，当然全是近期。要证这条必须按年份统计会议全集。
3. **只扫了 17 个 AI/安全会议，漏了软工四个**（ICSE/FSE/ASE/ISSTA）—— AgentSpec、ProbGuard 都在软工。
4. **会议名子串匹配**已经坑过 5 次（KG-Guard/ShadowPlay/TrustAgent/R-Judge/Causal Influence），应改用 OpenAlex source.id 或 Crossref container-title 精确匹配。

## 七、结论 5 工期

**偏乐观。** 3–5 天只够跑通「引擎 + 最小 demo」；要能跑出可信数字，5–8 天起步，要做对比实验 2–3 周。核心理由：论文把 fidelity 当命门（Differentiated Alignment 就是为了让模拟器的行为和目标 Agent 对齐），prompt 版模拟器保不住 fidelity，剪枝几乎不触发，风险分是噪声。
