# 读 BlindGuard 需要的最小图论

**结论先说：不需要学完整图论，也不需要群论。**
BlindGuard 只用到 7 个概念，全是离散数学第一章的内容。下面按论文里出现的顺序排。

**先说明一句**：图论和群论是两门课，没有先后关系。你现在学 group 不影响读这篇，这篇也不考群论。

---

## 1. 图 = 点 + 边

**一句话**：图就是把一堆对象（点）和它们之间的关系（边）画在一起。

**论文里的写法**：`G = (V, E)`
- `V` 是点集（vertex），在 BlindGuard 里**每个点 = 一个 Agent**
- `E` 是边集（edge），**每条边 = 两个 Agent 之间有过消息往来**

**卫星场景对应**：V 是星上那几个 Agent（姿态控制、遥测、指令解析……），E 是它们之间传过的消息。

**要点**：边是有向的还是无向的，论文会说明。BlindGuard 里消息有方向，所以是**有向图**。

---

## 2. 邻接矩阵 A

**一句话**：把图写成一个方阵，第 i 行第 j 列是 1 表示"i 和 j 有边"，0 表示没有。

**符号**：`A ∈ {0,1}^{n×n}`，n 是点数。

**为什么需要它**：计算机没法直接处理"画出来的图"，必须转成矩阵才能算。

---

## 3. 邻居 N(i) 和度

**一句话**：跟点 i 直接相连的那些点，叫 i 的邻居，记作 `N(i)`。邻居的个数叫度（degree）。

**在论文里的作用**：这是 BlindGuard 说的 **local neighborhood（局部邻域）** 那一层。

---

## 4. 节点特征 x_i

**一句话**：每个点除了"跟谁连着"，自己还带一组属性数字，叫特征向量。

**论文里的写法**：`x_i = SentenceBERT(R_i) ∈ R^D`
- `R_i` 是 Agent i 说过的文本（response）
- 用 SentenceBERT 把一段文字压成 D 维的一串数字
- **所以"节点特征"在这里 = 这个 Agent 说过的话的向量表示**

**这一步很关键**：它把"语言"变成了"数字"，后面才能做图计算。

---

## 5. 邻居聚合（GNN 的全部核心）

**一句话**：每个点更新自己的表示时，**把邻居的表示加权加起来**。

**公式**（看懂这个就够）：

```
h_i ← 把 { h_j | j ∈ N(i) } 加起来，再乘一个权重矩阵 W
```

**为什么这么干**：一个 Agent 单独看可能是正常的，但它如果跟一群被污染的 Agent 频繁通信，聚合之后它的表示就会"染上"那种特征。**这就是传播在数学上的样子。**

**在论文里的作用**：这是 **local neighborhood aggregation** 那一层。

---

## 6. 同质性 homophily

**一句话**：相邻的点倾向于"相似"。

**论文里为什么提它**：它指出**之前的方法假设"异常 = 结构异常"**（比如同质性突然变低、连接模式很罕见），**但真实的恶意 Agent 往往结构上完全正常，只是语义反常**（说假话、藏意图）。

**这是这篇论文的第二个 gap（Gap 2）**，也是它要解决的问题。

---

## 7. 边剪枝 edge pruning

**一句话**：把某些边删掉。

**在论文里的作用**：检测出恶意 Agent 之后，**剪掉它跟别人的边，阻止污染继续传播**。

**注意**：论文是"先检测、再剪边"，两步。剪边不是检测手段。

---

## 论文的三层「层次化编码」在说什么

BlindGuard 说之前的 GNN 只看局部，它要同时看三层：

| 层 | 看什么 | 对应上面的概念 |
|---|---|---|
| **个体 individual** | 这个 Agent 自己说什么 | `x_i`（节点特征） |
| **邻域 neighborhood** | 跟他通信的那些 Agent 什么情况 | `N(i)` 邻居聚合 |
| **全局 global** | 整个系统的态势 | 整张图 G 的汇总 |

**一句话理解**：判断一个人有没有问题，要看他本人说了什么、他身边的人什么情况、以及整个团队在干什么。

---

## 一个具体例子（卫星）

假设星上有 3 个 Agent：

```
  [姿态控制 A] ──→ [遥测 B] ──→ [指令解析 C]
```

- `V = {A, B, C}`，`E = {(A→B), (B→C)}`
- `A` 的邻居 `N(A) = {B}`
- 每个 Agent 的特征 `x_A, x_B, x_C` 是它最近说过的话的向量

**攻击**：攻击者往 B 收到的遥测里注入内容，把 B 的认知改歪。

- **B 自己的话**（个体层）看起来正常——它只是在转发数据
- **但 A 和 B 的通信模式变了**（邻域层）——B 开始要求 A 提供它以前从不问的参数
- **整个系统的消息流也变了**（全局层）

**只用一个层看不出来，三层合起来才看得出来。** 这就是论文说"要层次化编码"的理由。

## 你可以直接跳过的

这些论文**没有用到**，不用管：

- 树、森林、二分图
- 图的连通性、割、最大流
- 图的同构（那个才跟群论有关）
- 欧拉/哈密顿路径
- 平面图、图的着色

## 读论文时的对照表

看到这些词，直接对应到上面的号：

| 论文里写 | 是第几个概念 |
|---|---|
| `G = (V, E)` | ① 图 |
| agent / node / vertex | ① 点 = Agent |
| interaction / communication / edge | ① 边 = 消息往来 |
| `N(i)` / neighborhood / local | ③ 邻居 |
| `x_i` / node feature / SentenceBERT | ④ 节点特征 |
| aggregation / message passing | ⑤ 邻居聚合 |
| homophily | ⑥ 同质性 |
| pruning / remove edges | ⑦ 边剪枝 |
| GAD (graph anomaly detection) | 整套：在图上找异常点 |
