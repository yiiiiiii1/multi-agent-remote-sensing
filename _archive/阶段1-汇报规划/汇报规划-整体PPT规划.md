# 整体 PPT 规划（逐页）

> 用途：**做 PPT 的唯一依据**。每一页的标题、内容、配图、来源全部写明，照着做即可。
> 依据：导师**李倩**的三条语音要求（动机一页 → 模型一页 → 实验结果一页；每方向至少一篇；先讲脉络再讲论文）。
> 范例：导师发的两份 PPT（宋丽萍《遥感大模型》55 页 / 王哲《大模型调研》30 页）——每篇 2–3 页、按维度分页。
> 总页数：**45 页**（16:9）。素材见 `notes/卡片-*.md` 与 `figures/`（30 张已裁好）。
> 更新：2026-09-26

## 一、全局结构（六个部分）

| 部分 | 页 | 干什么 |
|---|---|---|
| 0 开场 | 1–4 | 标题、结论先行、目录、发展脉络 |
| 1 协作机制（**重点**） | 5–26 | 7 篇论文 × 3 页，每篇固定「动机 → 模型 → 实验」 |
| 2 模型结构 | 27–28 | 通信为中心的分类骨架 |
| 3 遥感落地 | 29–34 | GeoLLM-Squad（具体系统）+ Talemi 2026（领域综述） |
| 4 我的工作 | 35–37 | CAMEL 复现三条链路 + 遥感支线 |
| 5 对比与下一步 | 38–45 | 横向对比表、挑战、方向、致谢 |

**每篇 3 页的固定版式**（导师原话要求）：

| 页 | 标题格式 | 必须出现 |
|---|---|---|
| P1 | `论文名｜动机与难点` | 要解决什么问题 · 难点（论文自己点名的）· 研究目的 |
| P2 | `论文名｜模型` | **贴论文原图**，对着图讲模块、流程、通信机制 |
| P3 | `论文名｜实验结果` | 主实验（对比 SOTA 的数字）+ 动机实验（消融） |

## 三、版式规范（一次定好，全篇统一）

| 项 | 规定 |
|---|---|
| 尺寸 | 16:9（13.333 × 7.5 英寸） |
| 主色 | 深蓝 `#0F2A4A`（标题）、蓝 `#1F6FB2`（协作机制）、青 `#0E8F82`（对照/正面）、橙 `#C86A00`（难点）、红 `#B3261E`（遥感落点） |

| 表 | 用图片贴（已裁好的 `tbl_*.png`），不要用 PPT 表格重画 |

## 五、开工前要确认的三件事

1. **先出样张还是一次出全？** 建议先出**第 1–7 页**（封面、结论、目录、脉络 + MetaGPT 三页），确认版式后再铺满。改版式比改内容贵。
2. **pptx 怎么验收？** 用 PowerPoint / WPS 自己看，还是需要我导出图片来核对版式（需要本机能渲染 pptx）。
3. **`presentations/build_deck.py` 要不要复用？** 那是上一版（27 页、旧结构）的生成脚本，可以直接改造成这一版的生成器；也可以直接手工做。你选。
