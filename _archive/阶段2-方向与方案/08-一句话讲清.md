# 一句话讲清我在做什么

> 之前乱，是因为每查一次就有个想法被打掉。
> 这份就三层，从上往下看。

---

## 一句话

> **每条防御只保证自己那一环。n 环串起来还剩多少保证，没人算过。**

---

## 第一层：别人的结论（三条，都能引）

| 结论 | 出处 |
|---|---|
| **一层上的控制，对另一层的攻击检测力为零** | 综述，2604.23338（116 篇） |
| **现有防御弱可组合** | 综述，2606.10749（247 篇） |
| **只在最后查，比完全不查只强 2.3 个百分点** | The Hallucination Snowball，2608.14588 |

**三条说的是一件事**：单点防御有保证，串起来没保证。

---

## 第二层：我的问题（一句话）

> **n 环串起来，还剩多少？**

**没人算过。** 注意——不是"没人做防御"，是**没人算过串联之后的保证**。

---

## 第三层：我的做法（三步）

**① 每环验什么**

下游 Agent 用**自己能看到的东西**复核上游。它看不到原始数据，只看得到上游的结论。
**两条对不上，就拦在这一环。**

**② 怎么测**

测**传播深度**：一个错误判断能骗过几环。
**难点是错误归因**——最后输出错了，是第几环引入的？各环说的都是自然语言，位置很难定。

**③ 给上界**

前两步成立了，才能算"要几环、每环多强"。

---

## 九个切入点，现在什么状态

| 想法 | 状态 |
|---|---|
| 代理间消息通道加固 | 有（Beyond Single-Model，工作坊） |
| 授权沿链只缩不扩 | 有（Progent、CAPMAS） |
| 共享状态的溯源 | 有（MAP-Graph、PerMIT） |
| 跨 Agent 分歧当告警 | 有（EMNLP 2026 主会） |
| 下游复核上游 | **部分**——ARGUS 查依据链，但不在 Agent 之间做 |
| 按角色可见性查越界 | **部分**——检测手法有，角色判据没有 |
| 链上判断强度累积 | **部分**——现象被讲透，检测器没定 |
| 每环的最小独立证据集 | **没查到** |
| 每环串起来的保证 | **没查到** |

**四条有主，三条只剩缝，两条没查到。**

---

## 为什么之前显得乱

**因为我在追"没人做过"。** 每查到一篇，前一个想法就废了，于是再想一个新的。

**这是错的路子。** 单点机制这个年代基本都被占了。

---

## 现在定了

> **机制不新，问题新。**

- 机制：下游复核上游 + 链上累积（都有缝，都不干净）
- **问题：串起来剩多少保证（没人算过）**

**论文的主体是那个问题，机制只是它的落点。**

**不再换方向了。**

---

## 如果老师问"你这有什么新的"

**答**：机制层面我不新。新的是**问法**——现有工作都在报"我这一环拦住了多少"，没人报"串起来还剩多少"。

**而且这个问题不是我编的**：两篇综述一个说不可迁移、一个说弱可组合，一篇实验说最后一道关只值 2.3 个百分点。**三处独立来源指向同一个空白。**
