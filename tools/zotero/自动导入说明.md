# 把 papers/ 里的 PDF 自动导进 Zotero

跑一次，`阶段1-协作机制调研/papers/` 和 `阶段2-卫星多智能体防御/papers/` 里的 PDF 全部进 Zotero，
标题、作者、DOI、摘要由 Zotero 自己从 PDF 里抓（走的是 Zotero 官方连接器接口，不是模拟点击）。

已经跑过一次的结果：**19 篇**（阶段一 12 篇 + 阶段二 7 篇），元数据全部识别成功。

## 怎么用

**双击 `同步papers到Zotero.command`**，回车确认即可。

或者命令行：

```bash
cd ~/Documents/my-research/multi-agent-remote-sensing
python3 tools/zotero/import-papers.py                # 两个 papers 文件夹都扫
python3 tools/zotero/import-papers.py --dry-run      # 只看要导什么，不动 Zotero
python3 tools/zotero/import-papers.py --folder 某个目录
```

**条目会进 Zotero 左边当前选中的那个分类。** 想放指定的分类，先在 Zotero 里点好它，再跑。
（Zotero 的连接器接口没法指定分类，这是它本身的限制。）

## 去重规则

下面任意一条命中就跳过，所以重复跑是安全的：

1. `tools/zotero/imported.json` 里记着上次导过的
2. Zotero 里已有同名附件
3. 文件名里的 arXiv 号已在库里（比对 DOI / archiveID / url）
4. 文件名里抠出来的标题和库里某条目标题高度重合

文件名里既没标题也没 arXiv 号的（比如 `s44336-024-00009-2.pdf`），脚本会说「拿不准」并跳过，
要硬导加 `--force`。

## 出问题

- **报 `Zotero 没开（或 23119 端口不通）`** → 打开 Zotero。
- **报 400 / 403** → Zotero 设置 → 高级 → 确认勾了「允许其他应用与 Zotero 通信」。
- **导进去了但元数据是空的** → 在 Zotero 里选中那个附件，右键「抓取 PDF 元数据」。
  扫描件和中文期刊 PDF 经常抓不到，正常。
- **导错分类了** → Zotero 里选中那些条目，拖到目标分类即可（或右键 → 添加到分类）。

## 文件

| 文件 | 干什么的 |
|---|---|
| `import-papers.py` | 脚本本体，只用 Python 标准库，不装依赖 |
