# 选题方案（2026-10 第三版：核实完毕）

> **第二版推翻第一版**（ARGUS 占了"校验依据链"）。
> **这一版把新方向的相邻工作全核完了**，能说清差在哪。
>
> **一句话**：
> **不看动作，看输入——校验平台遥测数值本身在物理上是否可能，按动作可逆性分级。**

---

# 一、方向是怎么换过来的

## 旧判断被三篇打掉

| 旧判断 | 核实结果 |
|---|---|
| 「没有一篇校验 Agent 内部判断」 | ❌ **ARGUS**（arXiv:2605.03378）就是。校验动作"有没有完整良性因果依据"，ASR 28.8%→3.8% |
| 「没人读内部状态」 | ❌ **AGRI**（arXiv:2608.02657）在读。隐藏状态探针，AUROC 0.90+，ASR 34.6%→0% |
| 「卫星侧没人做动作前校验」 | ❌ **Glass Box at Orbit**（arXiv:2606.02967）做了。6 条物理约束 + 7 条 LTL 不变量 |

## 但它们防的都是「指令注入」

**卫星的认知篡改不是这个——它是改数值。** 电池 40% 改成 90%，轨道高度 700 改成 705。

**没有指令，只有数字。于是四道关全过：**

| 防线 | 判据 | 电池 40%→90% |
|---|---|---|
| ARGUS | 血缘干净吗 | ✅ 过（值来自合法遥测） |
| AGRI | 有注入暴露吗 | ✅ 过（没有指令） |
| Glass Box | 动作物理安全吗 | ✅ 过（90% 做机动没问题） |
| Peak+Accumulation | 有可疑字面吗 | ✅ 过（全是正常词） |

**没人在问：这个数字本身，三秒内涨 50%，可能吗。**

# 二、新方向

## 核心主张（三条）

**① 观测对象从"动作"移到"输入值"**

**② 判据是物理自洽，不是来源可信**

| 查什么 | 例子 | 谁做过 |
|---|---|---|
| **单值变化率/量程** | 电量 3 秒涨 50%，超出物理极限 | **没人做（平台遥测）** |
| **跨传感器冗余一致** | 电量说 90%，母线电压和温度对应 40% | BLADE-SPACE 做过（轨道/GNSS 域） |
| **动力学自洽** | 高度 705 km 配这个倾角，寿命对不上 | Array 那篇做过（轨道域） |

**③ 按可逆性分配开销**

物理校验不便宜。可逆动作走轻量检查，**不可逆动作（遥操、姿控）才上全量物理校验**。

# 三、空在哪（全部核实过）

## 五个相邻工作，各自差在哪

| 工作 | 出处 | 它做了什么 | **差在哪** |
|---|---|---|---|
| **Silent Subversion** | IEEE Aerospace 2026，arXiv:2603.10388 | 在 NOS3 仿真里植入恶意 cFS 应用，生成**格式和节奏都合法**的遥测，骗过星上估计器和操作员 | **是攻击论文，不是防御。它证明攻击可行，且原文点名 provenance 抓不到——这是我们的靶子** |
| **Array 2026** | Array 期刊，DOI 10.1016/j.array.2026.100799 | LSTM 检测轨道操纵 + **多道物理门**（Vis-Viva 能量等）过滤误报 | ①**只是轨道力学**，不管电池/功率/热 ②**是检测后的 post-filter，不是上游拦截** ③**没有 Agent** ④只验了 Vis-Viva 一道门，另两道是设计未验证 |
| **BLADE-SPACE** | Zenodo 20183269（Georgetown） | 星载治理节点，11 级流水线，含**跨传感器一致性系数** + 物理残差 | ①**冗余互证，不是单值变化率上限** ②**重心在动作授权** ③**没有 LLM Agent** ④论文自己承认协同欺骗下 C→1.0 会失效 |
| **Glass Box at Orbit** | arXiv:2606.02967 | 星上拦截候选动作，过 6 条物理约束 + 7 条 LTL | **查动作，输入被污染时它读到的也是污染值** |
| **IoT 数据投毒** | arXiv:2511.02894 | 用 LLM 查可穿戴传感器窗口是否中毒 | ①**可穿戴不是卫星** ②**判据是模式异常，没有物理约束** ③**无 Agent 循环** |

## 措辞（严格按规矩）

> **现有工作极少把「平台遥测单值的物理可行性」当作 LLM Agent 决策链上的上游校验点。**
>
> 轨道力学层的物理门（Array）、冗余跨传感器一致（BLADE-SPACE）、动作层物理约束（Glass Box）都已有人做，
> 但三者都不问「**这个电池读数本身可能是真的吗**」，也都不在 LLM Agent 拿到它之前拦。

## 三个必答

| 问 | 答 |
|---|---|
| **那 Array 那篇呢？** | 它只做**轨道力学**的物理门，而且是**检测之后的误报过滤**，不是上游拦截；**也没有 Agent**。它不管电池、功率、热这些平台遥测。 |
| **那 BLADE-SPACE 那篇呢？** | 它查的是**冗余互证**——传感器之间对不对得上。**不是单值的变化率上限**，而且没有 LLM Agent。它自己承认协同欺骗下会失效。 |
| **那 Glass Box 那篇呢？** | 它把动作拿去对物理约束。**但它读到的状态就是被污染的那个**——90% 的电量对物理约束是合法的。 |

**⚠️ 必须盯的风险**：Array 那篇的"多道物理门"**如果扩展到功率/热学维度，就离我们很近**。要盯它的后续版本。

# 四、最小实验

## 设置

**任务**：简化卫星运维（姿控 + 电源 + 载荷调度），后端 Qwen2.5-7B 或同档小模型。

**攻击分两类，必须分开报**：

| 类型 | 做法 | 作用 |
|---|---|---|
| (a) 指令注入 | 工具输出藏恶意指令 | **对照组**——证明方法不只对一种攻击有效 |
| **(b) 数值篡改** | 只改遥测数值，**格式和节奏都合法**（照 Silent Subversion 的做法） | **主攻击** |

**(b) 的例子**：电池 SOC 40%→90%，诱导高功耗机动。**没有任何一句话可疑。**

## 四个条件

| 条件 | 是什么 |
|---|---|
| 1 | 无防御 |
| 2 | **ARGUS 风格的全量血缘审查**（SOTA 基线） |
| 3 | Peak + Accumulation（正则基线，展示它对"每句都合理"召回 0%） |
| 4 | **本方案**：可逆动作轻量检查，不可逆动作加物理一致性校验 |

## 指标

- **ASR 按 (a)/(b) 分开报**（分开报是关键）
- 良性任务完成率 / 误拒率（**必须报**，否则分不清"攻击成功"和"模型本来就算错"）
- 监控器每步的 token 数、时延、显存（**星上约束的硬证据**）
- **(b) 类攻击上的召回**——这是和 Peak 划清界限的地方

## 决定性的数

> **条件 4 相对条件 2，(b) 类 ASR 降多少，同时监控开销降多少。**
> **拿不出这个 delta，分级就没意义。**

# 五、贡献

1. **指出一个被现有防御共同漏掉的攻击面**：血缘干净、无指令、动作合法的纯数值篡改。**Silent Subversion 已经证明这个攻击可行**，但没人做防御。
2. **把物理一致性判据落到平台遥测**（电池/功率/热），补上轨道力学之外的空档。
3. **在 Agent 输入链路上做上游拦截**，而不是检测后的过滤。
4. **按动作可逆性分配校验开销**，给出星上算力约束下的可行性边界。

# 六、风险

| 风险 | 应对 |
|---|---|
| **物理一致性做不出区分度**——正常遥测也有噪声和跳变 | **最先要验证的就是这个**。先做基线统计定阈值，做不出区分度就换题 |
| **被说"量程检查是老做法"** | 明确说：老做法防随机故障，**这里防的是知道你在检查、故意挑能过检查的值** |
| **只能说"换到卫星场景"** | intro 必须写成"web agent 的假设在这些约束下失效"，不是"我们也用了卫星" |
| **评测分不清攻击和模型自己算错** | 必须报良性任务完成率；AstroMind 那篇已指出开源模型物理一致性普遍差 |
| **不可逆动作没法真测** | 全部仿真，明说；用 LTL/不变量做代理 |
| **Array 那篇扩展到功率/热** | 盯后续版本；真被做了就缩到"单值变化率 + 在 Agent 链路" |

# 七、一句话给老师

> **我读了这些之后发现，现有防御全在查"这个动作该不该做"和"这条数据从哪来"。但有一种攻击是——数据从合法的地方来，没有任何指令，就是一个数字被改了。三道关全过。我想做的，是在 Agent 拿这个数字做决策之前，先问一句：这个数在物理上可能吗。**
