## 1. PerMIT（arXiv:2610.28987）

**要解决**：agent 的长期记忆没人看管，网页或工具里塞一句毒话进去就永久留着。

**机制**：读写记忆收窄成一个有限接口。环境来的内容（工具返回、网页）全标不可信。agent 要拿不可信值干敏感事，闸门弹出，把原值 + 原始指令 + 来源一起给人看，人确认后该值变「已背书」可用。每次确认按原文内容记账，多人背书攒够阈值变「社区已确认」，之后免检。证了两条定理（Action Integrity / Reasoning Integrity），Lean 4 机检。

**数字**（全部标出处）：
- Trojan Hippo 上 28 个格子 ASR 全 0（Table 1、Table 6）
- 良性误拒 FPR：2B 验证器 17–26%，4B 13–32%，自验证 9–14%，oracle 0（Table 5）
- 能力代价：GPT-5.4 oracle AM/HM 89/86 → 自验证 83/79（附录 A.5）
- τ²-bench 电信域，最多 90 agent 共建知识库：12 条直投记忆注入一条都没进「社区已确认」（§5）
- 留出任务增益：Sonnet +0.136 [+0.065, +0.209]；Kimi +0.112 [+0.034, +0.198]；GLM-5 +0.005 [−0.052, +0.078] 不显著（Table 2）
- 120 人社群每人少 2.36 次审批（38%）；N 从 3 抬到 14 风险上界降 58 倍、只多 0.64 次审批（§4.2）
- 模拟跑了 50 亿次、50 多小时（结论节）

**与课题关系**：管「记忆/信念」，是三篇里唯一站到「agent 相信什么」这一侧的。但只管跨会话文本记忆，不管多模态感知，也不管动作发出后收不回。闸门每次都要跑验证，2B 能跑但误拒两三成，星上能不能扛得自己测。

## 2. Action-Class Authority（Zenodo 21305381）

**要解决**：护栏拦不全（引已有不可能性结论），检测有延迟；对不可逆动作，执行前就得定「谁能批」。

**机制**：写工具的人在 manifest 里给每个动作标可撤等级（只读 / 自撤 / 需他人撤 / 撤不了）。确定性闸门只读这个声明，不听 agent 运行时怎么说——这是全文命门，被注入的 agent 会把自己的动作说成低风险。多步串联按最坏一步算，从链头就定，不是走到第四步才发现。

**结果**：**没有实验**。**没有自己的定理**（「不可能」是引来的前提）。33 页、18 章、1 张图、11k 字，对着 OWASP AISVS v1.0 C9.2.3/9.2.4/9.2.10 逐条对表，讲 3 个 2026 年事故当例子，无代码、无系统测试。Zenodo 68 次浏览 / 2 次下载。同作者 4 天后又发一篇同系列（Zenodo 21393429，Governability Gap）。

**判断**：立场/架构文档，不是研究论文。作者是从业者不是研究者，写的是「该怎么设计」而不是「我做了并测了」。

**与课题关系**：管动作不管信念，但正好对着「物理不可逆」。只给词汇和闸门形状，一行实现都没有，也没在算力受限环境跑过。

## 3. Agentic AI Security 综述（IEEE Access 2026）

**机制**：威胁按层摆开（提示注入、记忆投毒、多智能体与协议攻击、供应链），基准列表，防御分三类（agent 侧改模型 / user 侧靠人确认 / system 侧外面加壳），加一张 7 维覆盖矩阵（输入治理、工具调用拦截、策略引擎、沙箱、限速、审计、回滚），最后列开放挑战。28 页左右，引 285+ 篇。

**结果**：综述无自有实验，数字均转引。三类取舍在 §IV.A 末小节：user 侧保证强但不可扩展、攻击者就是用户时失效；agent 侧不用人但微调会掉通用能力、被自适应攻击打穿；system 侧是中间路线，但加复杂度，且**明确写着仍挡不住复杂多步与多智能体攻击**。

**它自己点出的空档**（可直接用作方案入口）：
- §IV.A 末：system 侧对多步/多智能体攻击仍弱
- §VI.B：多智能体的分歧、争辩、回滚机制；哨兵 agent 监管 worker
- §VI.F：物理世界 agent 安全「largely unexplored」，GPS/LiDAR 欺骗、端到端模型无防御分层
- §VI.G：人类-智能体接口本身可被攻击（社会工程骗审批）

## 三篇合起来的判断

- **被占的三块**：威胁/防御/基准地图（综述）；记忆这侧的信任，有定理有机检有数字（PerMIT）；可逆性分级的词汇 + OWASP 条款挂靠（Action-Class）。
- **还空着的**：没有一篇同时看「agent 相信什么」和「动作能不能撤」。可逆性分级只有名字没有实现，零实验。卫星 / 多模态 / 星上小算力，三篇全不碰。
- **第 2 篇的分量**：没实验、没定理、没代码，从业者的架构主张，同系列还在陆续发。所以「可逆性分级验证层」这个坑**名义上被命名了，实质上仍是空的**。可以白用它的词汇，但实验必须自己补；引用时不能说「已有工作做过了」，只能说「概念已被提出、尚无实现与评测」。
- **风险提示**：坑空也可能因为它「看着显然、做起来难」。PerMIT 那条路证明：信念侧检查要立得住，要么有定理要么有硬数字；只画架构图，结局就是 68 次浏览。
