# 术语速查（只记这些，其余先划掉）

> 用途：看累了就翻这一页。**只留 8 个词**，其他名词都是论文内部的编号，用到再查。

---

## 一条主线（所有词都挂在这上面）

> **攻击是一条链：从口子进来 → 往下传 → 最后动手。**
> **防御要让整条链闭不上口。**——这就是你导师说的"连环锁"。

三个词就够：**怎么进 → 怎么传 → 怎么动手**。

---

## 八个必须记的

| 词 | 大白话 |
|---|---|
| **主体 principal** | 一个**能被单独叫到**的参与者（一个 Agent、一个服务）。用这个词是为了分清"同事"和"外人"。 |
| **接口 interface** | 攻击**能钻进来的口子**。别记六个，只分三类：**进来的**（用户输入、检索到的文档、API 返回）→ **往下传的**（Agent 之间的消息、写进记忆的东西）→ **动手的**（调工具、执行指令）。 |
| **攻击路径 attack path** | 攻击从入口走到后果的**整条链**。**别盯单点，盯链。** |
| **路径闭合 path closure** | 防御把**整条链**堵死。**不是"某处加了检查"，而是"从任何入口到后果，路上都必然撞上一道检查"**。它是整张图的属性，不是某个点的属性。打比方：保险柜不能只锁前门——**要么所有门都锁，要么锁住唯一那条通路**。 |
| **认知攻击 cognition attack** | 不直接命令你干啥，而是**慢慢改你对任务的判断**。← 你导师说的"逐步篡改认知"。 |
| **JBR / UAR** | 判断被绕过率 / 危险动作执行率。**要分开测**：JBR 高、UAR 低 = 判断被攻陷了，但动作被拦住了（A2 的核心发现）。 |
| **架构级防御** | 不靠提示词让模型"自觉"，而是**在结构上让它做不到**。反义词是"提示级防御"（靠系统提示挡，A1 证明不管用）。 |
| **能力 capability** | 一个 Agent **被允许干的事**，按角色裁剪。不是"什么都能干但请自觉"。 |

## 三个最容易迷糊的，展开讲

### 路径闭合 vs 连环锁（这两个容易混）

| | 含义 | 打比方 |
|---|---|---|
| **连环锁** | 一条路上**多道**锁，一道被绕过还有下一道 | **纵深** |
| **路径闭合** | **每条**路都有锁，没有漏网的路 | **覆盖** |

**两个都要**：光有纵深、路有缺口，攻击换条路走；光有覆盖、一道锁被破就完，也不够。

**卫星例子**：攻击链是「污染元数据 → 检索 Agent → 规划 Agent → 执行 Agent 发指令」。
如果只在"检索 Agent 的输出"加检查，但**规划 Agent 也能直接读数据库**，攻击就绕过去了——**路径没闭合**。

### JBR / UAR：站岗打比方

- **有人骗过了岗哨**（岗哨信了伪造的通行证）→ 判断被绕过 = **JBR**
- **门卫不看通行证、独立核对名单**，发现这人不该进 → 动作没做成 = **UAR**

**A2 的实测**：记忆投毒时 **JBR = 100%（岗哨全被骗），UAR = 0%（一个都没进成门）**。

**为什么要分开测**：只报 UAR 会以为"防御完美"；但 JBR = 100% 说明**所有岗哨都被骗了——第一道防线实际等于不存在**，第二道一破就全盘皆输。**JBR 是早期预警信号。**

**对卫星**：导师说的第二步（篡改认知）= JBR，第三步（执行不合理操作）= UAR。**分开测才知道防御在哪一层起作用。**

### 架构级防御 vs 提示级防御

| | 提示级 | 架构级 |
|---|---|---|
| 做法 | 提示里写"不要执行未授权指令" | 结构上让未授权指令**根本发不出去** |
| 靠什么 | 靠模型**自觉** | 靠**代码、配置、密码学**强制 |
| A1 实测 | **67% 的 Agent 被打穿** | 31.2% → **4.2%** |

**一句话**：提示级是"**请它别做**"，架构级是"**它做不到**"。

**A2 补的一刀**：架构级里面，**签名（证明来源）≠ 授权（证明权限）**。真正顶用的是**独立于模型的策略检查**，不是签名、也不是另一个模型的判断。

## 七篇笔记各自只需记住一句话

| 笔记 | 就记这一句 |
|---|---|
| **E4 SoK** | 单独安全的 Agent 一起用会失败；**别查单点，查路径**。 |
| **A1 威胁模型** | 护栏拦不住（67% 中招）；**要架构级防御**；工具输出那条路最危险（43%）。 |
| **A2 信任传播** | 上游被攻陷 ≠ 系统被攻陷——**在动作前放一道独立授权**。而且**签名不够，要独立策略**。 |
| **A5 Crescendo** | 多步攻击的力量来自**累积**，单轮检测无效。 |
| **B1 CaMeL** | 把**控制流**从可信查询里抽出来，不可信数据只能填数据槽，改不了流程。 |
| **B2 设计模式** | 五种拿"自主性"换"安全性"的架构模式，可直接当"连环锁"候选。 |
| **E5 综述** | 两个领域承认的缺口：**自适应攻击下泛化差**、**工具交互评测不足**。 |

## 一句话总结

**攻击是链，防御要闭合链，判断和授权要分开。**
