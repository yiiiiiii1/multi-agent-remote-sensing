# 方向定位说明（写保研材料 / 跟导师聊方向时用）

> 背景：2026-09 会后方向改为"卫星多智能体安全防御"。这份说明解决一个问题——
> **这个方向在做 AI 的人眼里，到底算 AI 还是算安全？该怎么讲？**

---

## 一、结论

**这个方向不是"坑"，但有个"叙事风险"：你怎么讲，决定了你被归到哪个筐里。**

- 讲成"**做卫星网络安全的**" → 掉进传统网安的筐，做 AI 的老师不会看你
- 讲成"**做 LLM 多智能体系统的可信机制，卫星是验证场景**" → 落在 AI 里

---

## 二、关键区别：传统网安 ≠ AI 安全

| | 传统网安 | 这块（AI 安全） |
|---|---|---|
| 关键词 | 漏洞挖掘、渗透、逆向、密码学、工控 | **LLM Agent、prompt injection、对齐、评测** |
| 主要会议 | CCS / S&P / USENIX / NDSS | **ICML / NeurIPS / ICLR / ACL** |
| 组里的活 | 挖洞、写 exp、协议分析 | **训模型、跑实验、做 Agent 架构** |

**证据**：A1 发在 **ICML 2026**；B1 是 **Google DeepMind**；B2 是 **ETH + Google + Microsoft**。
→ **这些是 AI 圈的人，不是安全圈的人。**

---

## 三、三个真实风险

1. **面试时被误归类**——对方老师不做 Agent 的话，会把"多步注入防御"归成安全。
2. **方向偏窄**——"卫星 + Agent 安全"太具体，做 CV/NLP 的老师会觉得不对口。
3. **这个题可能不好发论文**（最实际）——卫星场景**缺公开数据集、缺 benchmark、评测难做**；做得太"航天"，投 AI 顶会会被质疑 evaluation 不充分。
   → **建议在方案阶段就把"用什么公开基准验证"想清楚。**

---

## 四、"只要能展现科研能力就行"——对一半

- **对**：保研看的是**有没有跑通完整闭环**（问题 → 方法 → 实验 → 结论）+ 独立贡献。本科生科研主要看这个。
- **不完全对**：**方向决定你被哪个组注意**。差太远，第一轮筛就被过滤。

**所以**：保研阶段方向不匹配的杀伤力**有限**，但**材料里全是"安全"字眼，就会被默认归到安全组**。

---

## 五、五条具体做法

1. **技术底座锚在"通用多智能体"**上，卫星只是验证场景（阶段一那 8 篇调研正好是通用底座，别浪费）
2. **成果优先投 AI 方向的会议/工作坊**，别投安全会议——**这决定了材料被谁看到**
3. **留一条能迁移到通用 Agent 的线**：如"多步攻击下的 Agent 认知一致性校验"，搬到网页 Agent、代码 Agent 都成立
4. **简历上别写"安全"**，写"**LLM 多智能体系统 / Agent 架构与可信性**"
5. **保研前至少有一篇能完整讲的工作**（工作坊 / arXiv 都行）——**这比方向重要**

---

## 六、两个待确认（影响结论精度）

1. **现在是大几？**
   - 本科冲保研 → "够用，重点补一篇完整工作"
   - 已读研考虑找工作 → 方向匹配权重更大
2. **目标组做什么？**
   - Agent / LLM 应用 → **完全对口**
   - 多模态 / 具身 → 需要重新包装
   - 传统安全 → 反而更对口

---

## 七、一句话记法

**对外一律说"我做 LLM 多智能体系统的可信机制"，卫星是其中一个验证场景——不主动说"我做安全"。**
