## 二、★ 两条必须记住的引用注意

### 1. 预印本要说"预印本"

**A2 / B2 / E4 都还没有正式 venue。** 汇报时说"arXiv 预印本"即可——**说成会议论文，导师一查就露**。

**为什么这也正常**：A2 和 E4 都是 2026 年 9 月才挂出来的（5 周左右），正在投稿很正常。**说"这是最新的预印本"反而是加分项**——说明你的检索在前沿。

### 2. ★ CaMeL 的数字有两个版本，别混用

| 版本 | AgentDojo 任务完成率 |
|---|---|
| **arXiv v2**（2025-06，我下载的那版） | **77%**（对比无防御 84%） |
| **IEEE SaTML 2026 正式版** | **67%** |

**引用时必须注明版本**：说"77%"就标 arXiv v2；否则用正式版的 67%。

**建议**：方案里用正式版 **67%** 更稳（有 venue 背书），或者两个都写清楚。

## 补：三篇新增论文的引用注意（2026-10 精读后核出）

### VIGIL（ACL 2026）

- **ASR 降幅口径不一致**：摘要和 §4 都说 **over 22%**，但 p2 的贡献列表写 **over 18%**。
  **引用按 22%**（摘要 + 结果节各一次，多数）。PPT 里用的就是 22%。
- 正文说「领先 DRIFT 22%~24%」，但按 Table 2 五个向量算出来的宏观平均对不上这两个数。
  **引用时写「原文称 22%~24%」**，不要自己算完当原文。
- 作者说静态防御工具流 UA「普遍掉到 12% 以下」，但 **CaMeL 在 Qwen3-max 上是 24.87%**，这句概括偏乐观。
- **它没做自适应攻击测试**——959 个案例都是固定模板。这条如果被问，如实说。

### Speculative Safety Honeypot（ICML 2026）

- **0% 有前提**：目标模型 **Qwen3-235B** + 重采样最多 5 次。
  换目标模型不是 0——**GPT-OSS-120B 是 14.9% → 0.7%**，论文措辞是「接近零」。
  **引用时要带「Qwen3-235B 上」这个限定。**
- **原文对 M、D 的记法自相矛盾**：Table 1 标题写 M=4，正文写 8。引用别照抄。
- 关键词核查（我自己数过）：全文 **belief / cognitive / internal state 各 0 次**，`action-level` 2 次。
  **这是 P14 那句论断的依据，可以放心讲。**

### Adaptive Adversaries（arXiv 预印本，无 venue）

- **它不是多智能体基准**：前沿矩阵测的是**单个防御方**，无工具、无检索、无外部状态变化。
  「multi-LLM」指被比较的模型多，**不是多个 Agent 协作**。**引用时要说准，否则容易被抓。**
- 0–1% vs 7.9–16.8% **可比**：同一批 945 场、同一批已保存轨迹，只是换算分截断。
- 论文自己说**回顾式重打分不等于真重跑**（判据变了会改停止时机和攻击方反馈）。
- **零成功不等于安全天花板**——主判据会漏，换宽判据从 108 变 152。
- 出处段（provenance paragraph）**只对伪造权威有效**，对会话密钥泄露无效。别推广。

### 补：SSH 的复现性问题（2026-10）

- **τ1、τ2 两个告警阈值的具体数值原文未给**，附录 D.2「Hyperparameter Analysis」**只有标题，正文是空的**。
- 加上 M/D 记法自相矛盾（Table 1 标题 D=4 / beam width 8，正文 p6 写 width 8 / 每步选 4 个节点，p7 又写 M=8、D=4）——
  **这篇做不了精确复现，要复现得自己调参。** 做对比实验前要算进这个成本。
- 它给的可复用锚点是 **Table 2：M=1 时风险暴露率已有 84.5%**——这是「星上砍到 M=1~2 也还有效」的依据。

**两条容易搞错的**：
- 第 4 篇原来被我标成「预印本」，其实已经中了 IEEE CARS 2026——**别低估它**。
- ACM DL 上有一篇《Securing Agents With Tracked Capabilities》，作者和 Design Patterns 高度重叠，但**是另一篇论文**，不是 Design Patterns 的出版版。别把两者当成一篇。

**引用规矩**：预印本必须标 `arXiv:xxxx`，不能写成会议。引用前回 arXiv 页面看 Comments 那一栏——预印本随时可能中，标注会过时。

### 补：CaMeL 的标题与系统名（2026-10 核实）

- **标题就是「Defeating Prompt Injections by Design」**，arXiv 和正式版一致，没有错。
- **但论文全称里没有「CaMeL」这三个字**——CaMeL 是论文提出的系统名。
  **PPT 上凡是讲 CaMeL 的地方，题名页必须挂上系统名**，否则读者接不上。
- **出处 IEEE SaTML 2026 已独立核实**：
  - IEEE Computer Society CSDL 的会议论文集里能查到
  - Florian Tramèr 主页 publications 也列了这一篇
  - arXiv 的 Comments 只写「Updated version with newer models and link to the code」，**没提 SaTML**——是作者没更新，不代表没中。

## 规矩：出处只能从一手来源核，不能从另一个 AI 的转述核（2026-10 踩过）

**经过**：豆包帮我审 PPT 时写「第 5 篇 CaMeL 经作者主页确为 SaTML 2026」「第 8 篇 VIGIL 经 dblp 确认为 ACL 2026」。
我**没核就写进了 PPT**。后来一查——**两句都对**，但当时是运气，不是方法：豆包在同一份审查里错了两次（说 `gemma4:31b` 不存在、说 `197 works` 存疑，实际原文都有）。

**规矩**：

| 来源 | 能不能当出处依据 |
|---|---|
| arXiv 的 Comments 字段 | **能** |
| 会议官方论文集（ACL Anthology / IEEE CSDL / PMLR / USENIX） | **能** |
| 作者主页 publications 页 | 能（弱一点，标一下） |
| **另一个 AI 的转述** | **不能** |
