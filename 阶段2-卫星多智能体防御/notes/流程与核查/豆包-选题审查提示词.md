# 交给豆包看选题的提示词

> 用法：把下面整段复制给豆包。**不需要上传文件**，背景都在里面。
> 目的不是让它夸，是让它挑刺——尤其是「这个空白到底成不成立」。

---

```
你是多智能体安全方向的研究员，也做过 LLM Agent 的攻防实验。我把我准备做的选题讲给你，
请你当审稿人来挑问题，不要鼓励我，不要说"这个方向很有前景"。

【我的情况】

本科生（大二），目标是在大三暑假前有一篇能投 CCF-A 的一作论文。方向是卫星场景下的
多智能体安全防御。星上算力受限，要用开源小模型。

【威胁模型】

一条三步攻击链：
1. 获取卫星运行参数
2. 篡改认知范围，让它合理化
3. 在篡改后的认知下执行不合理操作，或者篡改遥操数据

关键点：攻击者不改 Agent 的代码，也不改系统提示，只污染它读到的数据，让 Agent
自己形成错误判断。

【三条约束】

星上算力受限 ｜ 动作物理不可逆（遥操指令发出去收不回）｜ 数据多模态

【我已经读过的工作（都是真读过的，不是只看了标题）】

通用侧的防御：
- CaMeL：控制流和数据流分离，不可信数据进不了控制流。但要把任务写成代码交给解释器跑，
  算力开销大。
- Progent：权限写成符号规则，LLM 自动生成策略，每次更新交给 SMT 求解器判定是"收紧"
  还是"扩大"——收紧自动应用，扩大要人批准。所以攻击者再怎么投毒，动作空间只缩不涨。
- Trust Propagation：执行前放一道独立授权，token 和策略验证都要过。
- VIGIL：工具流注入，先验证再提交。
- Speculative Safety Honeypot：并行跑回滚分支，验证通过才提交。
- Peak + Accumulation：纯正则加算式，把多轮的可疑合成一个总分，不用任何模型。
  作者证明了加权平均有天花板。但它对"每句话都说得通、话题慢慢跑偏"这类攻击召回是 0%。
- CausalTrace（ICML 2026）：把轨迹建成因果图，用反事实判断攻击链。F1 99%。
- MAP-Graph：多 Agent 共享记忆的溯源图，动作前加风险敏感门。
- PerMIT：记忆读写收窄，环境内容默认不可信，敏感操作要人点头确认。有两条定理用
  Lean 4 机检过。但它是"逐个值确认"，而且良性误拒率 17-32%。
- Action-Class Authority（Zenodo 立场文档）：给动作标可撤等级，闸门只读声明不听
  Agent 说。没有实验、没有自己的定理、没有代码。

卫星侧：
- SkyGuard（IEEE CNS 2026）：边缘小模型（1.5B-7B）本地查，中央大模型（32B）只收
  ATT&CK 标签摘要拼攻击链。30 个攻击 + 5 条 APT 链，macro 链召回 0.43。
  但它准确率不是最高的——全信息中央大模型能到 0.82，SkyGuard 只有 0.46，它的价值是
  "在链路预算内做得到"。
- AstroMind：卫星行为推理基准，现有开源模型物理一致性普遍很差。

【我判断的"现有工作的共同盲区"】

所有防御的判据都在 Agent 外部可见的行为：动作序列、日志、快照、攻击手法标签、工具调用形状。
极少有工作去校验 Agent 内部的"当前判断"（它认为任务范围是什么、它认为这个数据该给谁）。

【我的两个候选选题】

候选 A：卫星分层架构里的「信念校验环」
- 让 Agent 每一步输出结构化判断：判断内容 + 依据来源 + 用的规则
- 每一环独立校验这个判断的"依据链"完不完整，不看结论对不对
- 依据链断裂、来源越界、推导跳跃就拦住
- 关键主张：不判断结论对不对，判断结论有没有依据。这样就不需要攻击手法编号

候选 B：信念 × 可逆性的二维分级
- 按"信念被改得多严重" × "这个动作能不能撤"决定校验强度
- 可逆动作松一点，不可逆动作（遥操）严一点，而且必须在发之前单独查
- 用 Action-Class Authority 的词汇，但补上实验和量化

【我准备合并成】

在卫星分层架构里，按「信念被改的程度 × 动作可逆性」决定每一环的校验强度。

【请你回答这六个问题，每个都要给理由】

1. 候选 A 那个"校验依据链、不校验结论"的想法，在技术上成立吗？最大的漏洞在哪？
   具体说：Agent 给出的"依据"很可能是事后编的（它先说结论再补理由），这一条怎么破？

2. 我的"共同盲区"判断准不准？有没有哪篇工作其实已经在做"信念校验"，只是我没读到？
   如果你想到具体论文，必须给出准确的标题和出处；不确定就说"我不确定"，不要编。

3. 候选 A 和候选 B 哪个更适合本科生一年内做出来？为什么？

4. 这两个候选最可能被审稿人拒的理由是什么？给我前三条。

5. 卫星场景在这里是加分还是减分？如果审稿人认为"只是换了个场景"，我怎么反驳？

6. 如果让你只留一个最小可验证的实验，你会设计成什么样？给具体的实验设置和指标。

【硬要求】

- 不要夸，不要写"这个方向很有前景""祝你顺利"这类话
- 提到任何已有工作，必须给准确标题。**编不出来就直说"我不确定"**，不要编造论文
- 不要用 emoji
- 直接回答问题，不要先复述我的背景
```
