# 三篇多步检测论文（大白话版）

用途：给本科生讲清楚每篇干了什么，并判断跟"卫星多智能体安全防御 + 轻量化"的关系。
阅读范围：CausalTrace 只有摘要 + ICML 海报 + 7 页 slides（无正刊全文）；另两篇读的 arXiv v2 全文。

## 1. Causal Detection of Multi-Step LLM Agent Attacks（ICML 2026 poster，作者 Viraaji Mothukuri、Reza M. Parizi）

**它要解决什么**：多步注入里每一步动作单看都合法，恶意要等整条流程跑完才显形；现有防御看单个动作或字面内容，抓不到序列结构。（摘要）

**它怎么做**：把 agent 执行轨迹建成因果图，边上标三类关系（数据依赖、信任传递、状态使能）；然后问反事实问题——如果注入内容没进来，这个有害结果还会不会发生，用 Pearl do-calculus 算；再用双向切片从结果回推、从注入点下推，把完整攻击链和注入点捞出来。输入是轨迹解析出的动作序列，输出 is_attack、attack_type、explanation、confidence、causal_details。

**结果**：CausalBench 含 100 万+ 条轨迹、14 个来源、8 类攻击、6 个应用域（海报 CausalBench 栏）。全系统 F1 99.2%，仅因果特征 99.1%，去 taint 99.0%，去 watermark 99.1%（海报 Feature Ablation）；因果边召回 91.4%、注入点检测 94.8%、瓶颈点检测 87.2%（海报 Overall Metrics）；分攻击类别因果边召回 81%–98%（海报 Recovery Rate by Attack Category）。摘要称优于内容基线且 LLM 推理开销小。全文未获取，故无 baseline 具体数值。

## 2. Peak + Accumulation（arXiv:2602.11247v2）

**它要解决什么**：多轮注入把恶意摊到好几轮，代理网关又不能调 LLM 来判（100–500ms 延迟、按 token 付费、自身可被注入），所以缺一个纯算式的跨轮聚合公式。（第 1 节）

**它怎么做**：每轮先用正则匹配五类模式（权重 0.2–0.5，命中权重相加截断到 1）得单轮分；总分 = 峰值 + 全程命中率×ρ + 类别多样性 + 升级奖励 + 重采样奖励，截断到 [0,1]，≥0.7 拦截。输入是一段对话各轮文本，输出 0–1 风险分与 allow/block。

其中关键论证：加权平均有"天花板"——各轮同分时平均值恒等于该分，20 轮持续攻击得分与单轮可疑完全相同（定理 1、Table 1：4 轮全是 role confusion 得 0.50，低于 0.7 阈值被放过）。

**结果**：10,654 段对话（588 攻击来自 WildJailbreak，10,066 良性来自 WildChat），recall 90.8%、FPR 1.20%、F1 85.9%、precision 81.5%、accuracy 98.4%（Table 3）。ρ 从 0.375→0.400 时 recall 77.4%→89.8%（+12.4 点），FPR 仅 1.11%→1.19%（第 6.2 节），原因是权重 0.3 的类别在 ρ=0.4 时 0.3+0.4 恰好过线。对 Crescendo 类"每轮都无害"的攻击 recall 为 0%（第 5.4 节与 out-of-scope 数据集）。

## 3. A Low-Latency Fraud Detection Layer（arXiv:2605.01143v2）

**它要解决什么**：风险是慢慢长出来的，单轮筛选必塌；需要在动作真正执行前几毫秒给一个风险分。

**它怎么做**：在 agent 提议动作之后、执行之前插一层。抽 42 个结构化特征分五组（prompt、session、tool、context、trajectory），trajectory 组是核心：累计工具风险及其单调性、近三轮高危工具占比、新收件人/新文件路径、敏感读取到外发的轮距。喂 XGBoost（180 棵树、深度 4），输出 0–1 分，三档处置 allow / restrict / block。

**结果**：12,000 段合成轨迹（模板生成，60/20/20 切分，测试集 1,200 良性 + 1,200 对抗，约 6,000 个前缀实例）。Table 3：AUC 0.97、precision 0.90、recall 0.66、F1 0.76、ASR 降低 0.92、单核 CPU 4.6ms；对比 Seq-window F1 0.71/43.1ms、Prompt-only F1 0.26/43.0ms（Qwen3-4B on A6000），即 9.4–9.5 倍加速。消融（Table 4）：trajectory 组单独 F1 0.76（近全模型 0.81）；去掉 trajectory 掉到 F1 0.68、ASR 降低从 0.94 到 0.76，多放进 18% 攻击。

## 跟课题的关系（三篇共同判断）

- 三篇判的都是**动作/轨迹层**，没有一篇校验 agent 内部"现在相信什么"。
- 三篇都不需要大模型在关键路径上，算力上都能搬（第 2、3 篇尤其轻；第 1 篇瓶颈在因果图规模）。
- 被占的地：多步检测的方法（因果链 + 反事实）、无算力聚合公式、执行前毫秒级拦截的工程三件套。
- 仍空着：认知状态校验、动作物理不可逆的单独校验链、多智能体间认知污染传播、多模态输入。
- 注意：以上"空着"只是"这三篇里没有"，写进方案前需专门检索，措辞用"现有工作极少关注"。
