## A. 攻击侧：多步注入与污染传播（先读这块，它定义威胁）

| # | 论文 | 一句话讲什么 |
|---|---|---|
| ★A1 | ✅已下 **Beyond Single-Model Injection: A Threat Model and Defense Architecture for Prompt Injection in Multi-Agent Systems**（arXiv:2609.22949）[链接](https://export.arxiv.org/pdf/2609.22949) | **最贴题**：专门给多智能体系统建注入威胁模型，并给出防御架构——基本就是你导师说的那道题 |
| ★A2 | ✅已下 **Trust Propagation and Structural Containment in Multi-agent LLM Pipelines**（arXiv:2609.17648）[链接](https://export.arxiv.org/pdf/2609.17648) | 讲**信任怎么在 Agent 之间传播**、以及怎么用"结构"把污染限制在局部——"连环锁"这几个字的技术版本 |
| A3 | **Prompt Infection: LLM-to-LLM Prompt Injection within Multi-Agent Systems**（arXiv:2410.07283） | 恶意提示能在 Agent 之间**自我复制式扩散**，一个被污染会传染一片 |
| A4 | **AgentPoison: Red-teaming LLM Agents via Poisoning Memory or Knowledge Bases**（NeurIPS 2024, arXiv:2407.12784）[链接](https://ar5iv.labs.arxiv.org/html/2407.12784) | 往 Agent 的**记忆或知识库**投毒，让它在该触发的时候做坏事 |
| A5 | ✅已下 **Great, Now Write an Article About That: The Crescendo Multi-Turn LLM Jailbreak Attack**（arXiv:2404.01833） | **多轮渐进式越狱**：每轮只问一点点，一步步把模型带到违规区——"逐步篡改认知"的标准范式 |
| A6 | **Not What You've Signed Up For: Indirect Prompt Injection**（Greshake et al., AISec 2023, arXiv:2302.12173） | 间接注入的**奠基论文**：污染外部数据源（网页/文档）就能劫持 LLM 应用 |
| A7 | **Ignore Previous Prompt: Attack Techniques For Language Models**（Perez & Ribeiro, arXiv:2211.09527） | 最早的提示注入系统化研究，把攻击分成"目标劫持"和"提示泄露"两类 |

|---|---|---|
| ★B1 | ✅已下 **CaMeL: Defeating Prompt Injections by Design**（arXiv:2503.18813）[链接](https://ar5iv.labs.arxiv.org/html/2503.18813) | Google DeepMind 的**从设计上防注入**：把能力控制和信息流控制做进系统，而不是靠过滤 |

## 建议的阅读顺序

1. **E1 综述**（半天，搭总纲）→ 2. **A1 + A2**（一天，定义威胁）→ 3. **B1 + B2**（一天，防御设计）→ 4. **C1 + C2**（一天，影像场景）→ 5. **D1**（半天，落到卫星）

**读的时候带着三个问题**：
- 它的攻击是**几步**的？每步改的是什么（参数 / 认知 / 动作）？
- 它的防御是**单点**还是**多环节**？（导师要的是多环节）
- 它的方案**算力代价**多少？能不能跑在小模型上？
