## 二、六条硬教训

**1. 结构从引言的论证链来，不从目录来**

论文的 Introduction 是作者设计过顺序的。先找那条链（威胁/问题 → 现有不够 → 我们怎么做 → 凭什么更好），再动手分页。

方法部分只做**一次同类合并**：讲「构成」的合一起，讲「流程」的各成一块。

**2. 配色先出三个色卡让用户选，不要沿用上一套**

白底截图多的论文（尤其从 PDF 裁的图），**不能配深色底**，否则图变成漂着的白块。

直接渲染三套配色的样张，让用户看图选，比说 hex 值有效。

**3. 裁图从 400dpi 起步，裁完必须量留白**

- 400dpi 裁 PDF 是矢量的，放大不虚
- **裁完用 PIL 扫一遍上下左右的白边**，因为留白会让两张并排的图错位
- 原图自带的图注（"Table 2. Performance on..."）**必须裁掉**，否则跟你加的图注重复

**4. 每页写完立刻渲染成 PNG 看，不要攒到最后**

一次生成 9 页再一起看，等于 9 个错误一起发现。生成一页、渲一页、看一眼。

**5. 页码和总页数用一个变量管**

炸过一次：前七页是 9 页版生成的，后三页是 10 页版，页脚 `/09` 和 `/10` 混着，封面还写「9 页」。

**改页数 = 全书重生成**，不能只改新页。

**6. 不要删用户可能开着的文件**

删了旧的 `SSH精读-9页.pptx`，用户 PowerPoint 还开着，直接报「无法读取」。

**文件名不要带页数**，就 `SSH精读.pptx`，加页删页都不用改名。

## 三、定稿结构（模板）

单篇论文精读，**11 页**：

| 页 | 内容 | 作用 |
|---|---|---|
| **P01** | 封面 | 英文全题 + 作者 + 会议 |
| **P02** | **论证架构页** | 核心研究问题 + 四个板块 + 页码索引 |
| **P03** | 两类威胁 / 论文的"打什么" | 用论文动机图 |
| **P04** | 两个问题 / 论文的"补什么" | 现有做法的两个缺口 |
| **P05** | 方法 A | 系统构成 + 训练（合并） |
| **P06** | 方法 B | 流程一，用论文模型图 |
| **P07** | 方法 C | 流程二（验证/打分/响应） |
| **P08** | **Key advantages** | 从引言拎出来，单列，跟方法平级 |
| **P09** | 证据一 | 表或图，回答"防得住" |
| **P10** | 证据二 | 表或图，回答"灵不灵/误不误报" |
| **P11** | 边界与代价 | **局限表 + 前提**，不替论文说好话 |

**P02 怎么画**（这一页最关键，直接回答"结构认知"）：

```
┌ 核心研究问题（橙色竖条）─────────────────────┐
│ 现有防御只能回看历史——能不能在动手之前预判？   │
└──────────────────────────────────────────┘

┌ 01 ─┐ ┌ 02 ─┐ ┌ 03 ─┐ ┌ 04 ─┐
│两类威胁│ │两个问题│ │方法ABC│ │Key adv│
│ 一句话 │ │ 一句话 │ │ 一句话 │ │ 一句话 │
│  P03  │ │  P04  │ │P05-07│ │  P08  │
└──────┘ └──────┘ └──────┘ └──────┘

┌ 证据与边界（橙色竖条）──────── P09–P11 ─────┐
└──────────────────────────────────────────┘

一句话：从「回看历史」改成「动手前推演」。
```

**证据与边界单独一条横带**——因为它不在这四个论证点里，是拿来说明"凭什么成立"和"哪里不成立"的。

## 四、七步流程

**1. 定结构**
读引言，抽出论证链 → 落成 11 页清单 → 给用户看一遍页单。

**2. 定视觉**
出三套配色样张（渲染成 PNG，用真实的数字和图做样张）→ 用户选。

**3. 裁图**
400dpi 裁 PDF → 量留白 → 裁掉原图注 → 逐张目检。
表格先判断能不能整张放：按"正文区宽度 ÷ 表的 pt 宽 × 7pt"估算字号，**低于 18px 就不能整张放**，要么只取部分行/列，要么原生重画。

**4. 写规划文件**
`design_spec.md` + `spec_lock.md`，走 ppt-master 的 schema 校验。
**颜色、字号、页数只写在这里**，SVG 里不许出现未声明的字号。

**5. 逐页生成 SVG**
1280×720，正文区 1136×608，页边距 72/56。
每页只干一件事；标题给判断句，不给名词。

**6. 渲染目检 + 量像素**
每页渲成 PNG 看一遍。并排的图表**必须量像素对齐**：

```python
# 按列扫暗像素，量每块的第一行和最后一行
band(x0, x1, ytop, ybot)  # 返回 (首行y, 末行y)
```

**7. 出 PPTX**
质量门 0 错误才算过。

## 五、交付前检查清单

**每页过一遍：**

- [ ] 汉字没超出正文区（24px 字号，一行约 44 字）
- [ ] 并排的图表，**顶边对齐、底边对齐、图注同一行**（量像素，不靠眼）
- [ ] 图注不贴分隔线（至少留 16px）
- [ ] 图/表里没有论文自己的原图注
- [ ] 一个页面上只有一处强调色（青绿给方法、焦橙给代价）
- [ ] 页脚 `/ NN` 全书一致

**全书过一遍：**

- [ ] 页数和 `TOTAL` 变量一致
- [ ] P02 架构页的页码索引跟实际页对得上
- [ ] 论文原图加了边框/底色吗（不许加）
- [ ] 数字口径写清楚了吗（99.5% 标 HarmBench、96.0% 标 Circuit Breaker；45.13 标 Overall）
- [ ] 术语第一次出现时定义了（如 86M = PromptGuard 检测器，不是探子）

**给用户之前：**

- [ ] 文件名不带页数（`SSH精读.pptx`，不是 `SSH精读-11页.pptx`）
- [ ] 没删用户可能开着的旧文件
