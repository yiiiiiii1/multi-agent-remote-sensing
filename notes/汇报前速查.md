## 三、5 个高风险问题 + 答案 + 原文在哪

### 1. "MacNet 为什么随机拓扑最好？"（你昨天没答上来）

> 交互过密（mesh）会造成**信息过载**，反而妨碍 Agent 的反思和细化；随机拓扑容易产生**小世界性质**，兼顾连通性和效率。一句话：不是连得越多越好。

原文：MacNet **p.7** "Shape Perspective" 那段。

### 2. "Yan 那篇里，通信策略和通信范式有什么区别？"（昨天没答上来）

> **策略 = 什么时候说**（逐个 / 同时 / 同时+摘要器）
> **范式 = 信息怎么表示和解读**（消息传递 / 言语行为 / 黑板）
> 一个管时序，一个管形式。

原文：策略在 Yan **p.7 §4.1**，范式在 **p.9 §4.2**。

### 3. "这七篇里哪些是层级结构，哪些是扁平结构？"（昨天没答上来）

> **层级/集中**：MetaGPT（SOP 流水线）、ChatDev（阶段分层）、AgentVerse（recruiter 与评估者在上）、GeoLLM-Squad（星形中心化）
> **扁平/对等**：CAMEL（双 Agent）、Multiagent Debate（同构对等）
> **看配置**：AutoGen、MacNet（DAG 可扁可层）

原文：Yan **p.3–4 §3.1** 给了五种架构的定义和代表工作。

### 4. "你说的 agentic correctness 是什么指标？"（昨天没答上来）

> Agent 有没有**按正确顺序调用正确的工具**——正确步骤数 ÷ 总步骤数。是**过程指标**，不看最终答案对不对。

原文：GeoLLM-Squad **p.3** "Metrics." 开头。

### 5. "如果多智能体的 F1 和单智能体差不多，怎么证明有用？"（昨天没答上来）

四条路：

1. 换指标：加过程指标（验证步骤有没有做、顺序对不对）、幻觉率、变化类别的召回率
2. 看边界：任务变复杂时单 Agent 会不会崩（GeoLLM-Squad 就是这么论证的）
3. 看成本：同样正确率下是不是更省 token
4. 分错误类型：单 Agent 的错误是不是集中在"偏爱无变化"，多 Agent 有没有压下去

**还有第五条：如果确实没差别，那本身就是结论，照实报。**

## 四、每篇 30 秒版本（被点名时开口就用）

**CAMEL**：两个 Agent 靠角色设定自主协作，人类只在开头出现一次。人类评委盲评，它赢 76.3%，单模型赢 10.4%。
难点是角色反转、复述指令、敷衍回复。

**MetaGPT**：把人类团队的 SOP 编码进多智能体，Agent 之间传 PRD、设计、任务列表这些**结构化文档**，还有**可执行反馈**跑测试纠错。HumanEval Pass@1 85.9%。

**AutoGen**：把"Agent 之间怎么对话"变成**可编程接口**，Conversable Agent + 自动回复，没有中央调度器。ALFWorld 加 grounding agent 后 +15%。

**ChatDev**：用**聊天链**把开发拆成原子对话，3 阶段 5 子任务；防幻觉靠**交际式去幻觉**（不确定就先问再答）。可执行性 0.88，MetaGPT 0.41。

**MacNet**：用 DAG 组织 Agent，把上下文增长从平方级降到线性级，能扩到千级。**随机拓扑最优**，2⁴ 是性价比甜点。

**AgentVerse**：团队是活的——recruiter 按目标现场招人，评估反馈决定去留。还观察到**破坏性行为**（为拿材料杀队友、拆图书馆）。

**Multiagent Debate**：唯一的**非合作**协作，用分歧做校验。3 个 agent × 2 轮，六类任务全面超过单模型。

**GeoLLM-Squad**：把**编排和求解拆开**，编排者写"排班表"，Agent 之间零通信（星形）。真实遥感工作流上正确率 43%→60%，而且**任务超过 3 个领域时单 Agent 会崩、多 Agent 稳住**。

**承认口径细节，不承认数字**——数字你 PPT 里都有。
### 6. "GeoLLM-Squad 建在 AutoGen 上，怎么保证是星形？"（这是看起来最像矛盾的一问）

> auto-reply 管的是**怎么回**，不管**回给谁**——论文原话是"把回复**发回给发送者**"。拓扑由代码定：编排者跟每个子 Agent 各建一条双人对话，子 Agent 的发送目标里根本没有彼此，所以物理上绕不开中心。
> 另外 AutoGen 自己的 GroupChat 本来就是星形（消息全经 manager 转发），所以星形在 AutoGen 里是现成模式。

补充一句更有力的：**图的结构是写死的，图上流动的内容是涌现的**——涌现的是轮数、要不要执行代码、报错怎么修、什么时候结束；不是谁跟谁连。
