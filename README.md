## 当前阶段（阶段二）

**卫星场景下，构建能抵御多步注入攻击的多智能体防护机制，并兼顾轻量化。**

威胁是"逐步篡改认知"的攻击链：① 获取卫星运行参数 → ② 篡改认知范围使其合理化 → ③ 在篡改后的认知下执行不合理操作或篡改遥操数据。单步防御拦不住，所以要"连环锁"式的多环节防护。
